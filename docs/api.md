# API

Este documento queda preparado para definir los endpoints del backend Laravel.

## Convenciones recomendadas

- Prefijo base: `/api`.
- Respuestas JSON.
- Validacion de entrada en Form Requests de Laravel.
- Autenticacion mediante tokens o sesiones seguras, por decidir.
- Versionado futuro mediante `/api/v1` si el proyecto lo requiere.

## Modulos iniciales previstos

- Autenticacion.
- Usuarios y roles.
- Nadadores.
- Tutores.
- Entrenadores.
- Grupos.
- Horarios.
- Asistencia.
- Competiciones.
- Tiempos.
- Informes.
- Logros.
- Metas.
